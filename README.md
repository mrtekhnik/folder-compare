# Сравнение папок и файлов

Офлайн-приложение для Chrome на ПК: сравнение двух папок (только чтение).

Открыть: https://mrtekhnik.github.io/folder-compare/

Текущая версия: этап 1, 1.5 — сравнение по пути, размеру и дате с допуском, исключения по маскам, таблица с группировкой по подпапкам.

## Публикация новой версии
- Увеличить вместе `APP_VERSION` (и `APP_DATE`) в `index.html` и `VERSION` в `sw.js`.
- Новая версия скачивается в фоне и ждёт: у пользователя появляется панель «Доступна новая версия — Обновить».
- `version.json` нужен только для перехода со старых версий (до 1.3), которые проверяли его сами.

## Автотесты (нужен playwright)
- `tests/update.test.js` — обновление по кнопке, офлайн, чужие кэши, переход с v1.2.
- `tests/sw-cache.test.js` — service worker не удаляет кэши других приложений.
- `tests/phone.test.js` — раскладка для телефона (шапка в одну строку, без горизонтальной прокрутки) и ПК.
- `tests/two-panels.test.js` — вид «Две панели»: файлы A и B напротив друг друга, переименованные рядом, телефон — имя сокращается в середине.
